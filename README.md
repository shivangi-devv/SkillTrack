# 🤖 SkillTrack – AI-Powered Career & Skill Analyzer

**Discover your skills. Identify your gaps. Build your future.**

SkillTrack is an AI-powered application developed using Python, Streamlit, and Generative AI. It aims to help users analyze their skills and explore career development opportunities.

## 🚀 About the Project

SkillTrack is designed to make skill analysis easier with the help of Artificial Intelligence. It uses Google's Gemini API to bring AI-powered insights into the application.

## ✨ Key Highlights

- 🤖 AI-powered skill analysis
- 💡 Generative AI integration using Gemini
- 📊 Skill assessment and insights
- 🎯 Career-oriented guidance
- 🖥️ Interactive web interface using Streamlit

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Frontend:** Streamlit
- **AI Integration:** Google Gemini API
- **Libraries:** Python dependencies listed in `requirements.txt`

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project folder:

```bash
cd SkillTrack
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Create a `.env` file in the project directory and add your Gemini API key:

```env
GEMINI_API_KEY=your_api_key_here
```

5. Run the application:

```bash
streamlit run main.py
```

## 🔐 Security

- API keys are stored in environment variables.
- The `.env` file is excluded from GitHub using `.gitignore`.
- Never share your private API keys publicly.
